# 스타일 패키지 작성 규약

스타일 패키지는 승인된 표현 방식의 Prompt와 관련 UC를 통째로 저장하는 단위다. 입력 슬롯은 `BASE`다.

공통 형식은 [storage.md](../../formats/storage.md#재사용-패키지-json)를 따른다. 신규 스타일의 ID는 `st001`부터 미사용 번호를 사용한다.

## 이름

사용자가 직접 지정한 그림체명이 있으면 그 이름을 쓴다. 지정이 없으면 승인된 Prompt의 작가 태그를 프롬프트 가중치가 높은 순으로 최대 3명 골라 `작가명 + 작가명 + 작가명`으로 짓는다.

**세부 규칙**

- 사용자가 지정한 이름은 이후에도 자동 이름으로 덮어쓰지 않는다.

### 자동 이름에 사용할 작가 선정

**세부 규칙**

- 가중치가 같으면 원문 등장 순서를 따른다.
- 가중치가 없는 작가 태그는 1로 취급한다. UC와 0 이하 가중치의 작가 태그는 이름 선정에서 제외한다.
- 같은 작가는 한 번만 표기하며, 반복되면 가장 높은 가중치를 기준으로 삼는다.

### 표시 이름과 갱신

**세부 규칙**

- 표시 이름에서는 `artist:` 접두사와 가중치 문법을 제외한다. `artist:` 없이 쓰인 표현도 작가 태그로 확인되면 포함한다. 선정할 작가가 3명보다 적으면 확인된 수만 나열한다.
- 이름 변경 시 해당 구성의 `name`과 스타일 인덱스를 함께 갱신한다.

## 기존 스타일과의 판정

[패키지 등록](../../workflows/package_registration.md)에서 지정된 스타일을 판정할 때 INDEX로 후보를 찾고 기본 스타일과 각 변경본의 실제 Prompt·UC를 비교한다.

| 비교 결과 | 판정 |
|---|---|
| 입력 슬롯·재사용 범위가 같고 Prompt·UC가 [실행문 대조](../../formats/storage.md#실행문-대조) 기준으로 일치한다. | 해당 버전을 재사용한다. |
| 작가 구성이 같고 아티스트 가중치만 다르다. | 기존 스타일의 변경본이다. |
| 작가의 추가·제외, 매체·렌더링·색감·UC 변경이 있다. | 전체 표현 구성과 변경 범위를 비교해 변경본 또는 신규로 판정한다. |
| 작가가 없거나 판정 근거가 부족하다. | 자동 분류하지 않는다. |

사용자가 기존 스타일의 변경본으로 관리할 관계를 명시했다면 그 분류를 우선한다.

**세부 규칙**

- 가중치만 다른 경우는 순위 변화와 관계없이 변경본이며, 전체 작가에 적용한다.
- 상위 작가 최대 3명은 표시 이름을 만드는 기준이다. 상위 작가의 구성·순위 변화나 단순 재배열만으로 신규 스타일을 확정하지 않는다.
- 작가 추가·제외 등의 변경에서는 관계가 불명확한 경우에만 기존 스타일 변경본인지 신규인지 확인한다.
- 판정에 맞추려고 승인된 문자열을 바꾸지 않는다.

## 버전 저장

- 신규 기본 스타일은 `<id>.json`의 `variants.base`에 저장한다.
- 등록 대상이 변경본이면 같은 파일에 `v01`, `v02`처럼 마지막 번호 다음의 키를 추가한다.
- 스타일 INDEX는 `ID | 구성 | 이름 | 입력 슬롯` 열을 사용한다. 각 구성은 한 행이며 `base` 아래에 변경본을 번호순으로 배치한다.

**세부 규칙**

- 동일본 재사용에는 새 키를 만들지 않는다.
- 기본과 각 변경본의 승인된 Prompt·UC·출처·샘플 연결을 각각 보존한다. 구체적인 필드와 조회는 [패키지 JSON](../../formats/storage.md#재사용-패키지-json)을 따른다.
- INDEX의 각 행은 기본 ID의 JSON을 연결하고 구성 키를 표시한다.
- 기존 승인 패키지를 변경본으로 편입할 때는 전체 문자열·출처·승인 근거를 보존하고 패키지 참조를 함께 갱신한다. 실제 실행이 동일한 재배치는 재생성·재승인을 요구하지 않는다. 이전 HTML 주소는 [표시 그룹의 별칭](../../viewer/README.md#표시-그룹-저장)으로 연결하고, 편입되어 비워진 ID는 재사용하지 않는다.

## 대표·서브 이미지

- 대표·서브 생성은 [스타일 공통 랜덤 생성](../../workflows/package_images.md#스타일-공통-랜덤-생성)을 따른다. 기존 스타일 Prompt·UC에 공통 랜덤 템플릿을 연결한다.
- 대표·서브는 구성별로 사용자가 채팅에서 명시적으로 선택한다.
- 저장·교체·해제는 [패키지 이미지 워크플로우](../../workflows/package_images.md)와 [자체 이미지 규약](../../formats/storage.md#패키지-자체-이미지)을 따른다.

**세부 규칙**

- 랜덤 선택이 끝난 실제 입력과 seed·설정은 이미지마다 기록한다.
