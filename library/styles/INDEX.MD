# 스타일 인덱스

승인된 스타일의 기본본과 변경본을 찾는 인덱스다. `ID` 링크는 패키지 JSON을 열고, `구성` 열은 그 파일 안의 구성 키를 표시한다.

`base`는 기본본이며 `v01`부터는 변경본이다. 이름·판정·저장 기준은 [스타일 작성 규약](FORMAT.md)을 따른다.
