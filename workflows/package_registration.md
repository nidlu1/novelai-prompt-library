# 지정한 샘플에서 패키지 등록

사용자가 **출처 샘플과 저장할 대상**을 지정해 등록을 요청할 때 시작한다. 샘플 승인만 요청하면 [샘플 최종 승인](refine.md#샘플-최종-승인)으로 작업을 마친다.

| 순서 | 담당 | 할 일 |
|---|---|---|
| 1 | 사용자 | 샘플과 저장할 스타일·캐릭터·장면 청크를 지정한다. 여러 대상을 함께 지정할 수 있다. |
| 2 | 에이전트 | 샘플의 승인 단계와 기준 이미지를 확인하고 요청에 해당하는 묶음을 찾는다. |
| 3 | 에이전트 | 지정한 묶음만 같은 종류의 기존 구성과 비교해 동일본 재사용·바리에이션 추가·신규 등록을 판정한다. |
| 4 | 에이전트 | 해당 구성과 출처를 연결하고 검증한 뒤 등록하거나 재사용한 ID와 구성 키를 알린다. |

**세부 규칙**

- 2: 기본 출처는 [최종 승인 기록](../formats/storage.md#최종-승인-기록)의 단계와 이미지다. 다른 단계를 명시하면 그 단계의 승인된 이미지를 확인한다. 승인 출처가 없으면 등록을 보류한다.
- 2: 샘플이나 대상이 불분명하면 빠진 항목만 확인한다. 같은 종류의 후보가 여럿이면 이름이나 슬롯을 제시한다. 요청 밖의 묶음은 등록하거나 새로 연결하지 않는다.
- 2: 기존 평면 REG를 다룰 때는 [REG JSON의 변환 기준](../formats/storage.md#reg-json)을 따른다. 승인된 실행을 그대로 표현할 수 없으면 원문을 보존하고 등록을 보류한다.
- 3: 해당 종류의 INDEX와 실제 구성을 [스타일](../library/styles/FORMAT.md#기존-스타일과의-판정)·[캐릭터](../library/characters/FORMAT.md#기존-캐릭터와의-판정)·[청크](../library/chunks/FORMAT.md#기존-청크와의-판정) 판정 기준으로 비교한다.
- 4: [인덱스와 샘플 연결](../formats/storage.md#인덱스와-샘플-연결)에 따라 선택한 묶음의 패키지 참조와 구성의 출처를 기록한다. 같은 구성은 기존 키를 재사용하고 같은 샘플 실행·이미지 출처는 한 번만 기록한다. 새 구성이 생긴 경우 해당 종류의 INDEX를 갱신한다.
- 4: 새 구성의 자체 갤러리는 비워 둔다. 이미지 지정은 [패키지 이미지 절차](package_images.md), 검증과 HTML 갱신은 [저장 시 확인](../formats/storage.md#저장-시-확인)을 따른다.
